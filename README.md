# Business Requirements
* Business Rule:
   - The Oracle Baseball League sells baseball-related products
   - Customers are able to make multiple orders
   - Customers who represent a team get a discount depending on the number of players
   - OBL has a team of sales representatives that handle customer complaints
* Assumptions:
   - Product prices have been defined
   - Customers are able to identify themselves to the system
* Problem:
   - System needs to be able to store order data, and run calculations and verification for each order
